# Undangan Desy & Huan

Undangan digital tasyakuran & resepsi. Situs statis (HTML/CSS/JS), tanpa build.

- Buka `index.html?to=Nama+Tamu` untuk menampilkan nama tamu.
- Cover video: `assets/video/cover.mp4` (freeze di `cover-last.jpg`).
- Musik: `assets/audio/music.mp3` (Janji Suci by Yovie & Nuno).
- Foto orang tua: `assets/img/ortu.jpg`.
- Nomor WhatsApp ucapan: isi `WA_NUMBER` di `assets/js/main.js` (masih kosong).
- Spesifikasi: `docs/PRD.md`.
